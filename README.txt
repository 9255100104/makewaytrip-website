MAKEWAY TRIP WEBSITE - STARTER PACKAGE

CONTENTS
- index.html: bilingual website homepage and property listings
- style.css: responsive styling
- app.js: language switch, mobile menu and WhatsApp enquiry form
- admin.html: admin setup information page

DEPLOY TO CLOUDFLARE WORKERS (STATIC ASSETS)
1. Extract this ZIP on your computer.
2. In Cloudflare, open Workers & Pages > snowy-pine-a577 > New deployment / Upload static files.
3. Upload the extracted folder contents (index.html, style.css, app.js, admin.html). If the uploader accepts a folder, select the extracted folder.
4. Deploy, then visit https://makewaytrip.in

- The booking form opens WhatsApp with an enquiry message; it does not confirm a reservation.
